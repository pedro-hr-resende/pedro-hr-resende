# **Olá, eu sou o Pedro!**

Sou Engenheiro de Dados e atualmente atuo no <a href="https://www.tribanco.com.br/empresa/">Tribanco</a>, onde participo ativamente da resolução de problemas de negócios complexos, mantendo uma forte interface com as áreas de negócio. Tenho experiência no design e implementação de processos de ETL e ELT, garantindo a integridade e o fluxo contínuo de dados entre diferentes sistemas.

Sou apaixonado pela área de dados e busco constantemente novas formas de aplicar machine learning para solucionar desafios diversos.
